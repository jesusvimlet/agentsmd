# AgentsMD

A reusable, tool-independent knowledge base of development instructions for AI coding agents.

AgentsMD defines consistent engineering standards, architecture, project structure, testing, security, and development workflows across different projects.

It works with any AI coding agent that supports `AGENTS.md` or can be instructed to read it.

## What's included

- **`AGENTS.md`** — Main development instructions, including stack, architecture, Git workflow, testing, dependencies, and agent workspace conventions.
- **`agents/`** — Detailed instructions for backend, frontend, persistence, schemas, and testing.
- **`AGENTS-SETUP.md`** — One-time configuration guide for adapting the instructions to a new project.
- **`CLAUDE.md`** — Compatibility file instructing Claude to follow `AGENTS.md`.

## Getting started

### 1. Copy the template

Copy the **contents** of the `template/` directory into the root of your new or existing project.

```text
your-project/
├── AGENTS.md
├── AGENTS-SETUP.md
├── CLAUDE.md
└── agents/
```

Do not copy the `template/` directory itself, only its contents.

`CLAUDE.md` is only necessary if you use Claude Code.

### 2. Run the initial setup

Open the project with your preferred AI coding agent and send:

> Read `AGENTS-SETUP.md` and guide me through all pending TODOs. Review the existing project, determine which instructions apply, and help me configure the relevant AGENTS.md files. Ask before making configuration decisions. Do not introduce unnecessary technologies or components.

The agent will help you review the configuration, including the technology stack, authentication provider, database, and any additional project-specific requirements.

Existing standards are conditional: instructions for components that do not exist in your project do not apply.

### 3. Remove the setup file

Once every TODO has been reviewed and resolved, delete `AGENTS-SETUP.md` from your project.

The setup process is complete. You do not need to repeat it during normal development.

## Daily usage

Work with your AI coding agent normally.

The agent should read `AGENTS.md` and follow the applicable instructions in `agents/`.

These instructions establish consistent development practices without requiring every project to use the same technologies or components.

## Agent workspace

AgentsMD reserves `.agent/` for working artifacts generated by AI agents.

```text
.agent/
├── discover/    # Research and technical investigations
├── issues/      # Bug investigations and issue reports
└── tmp/         # Temporary diagnostics and experiments
```

Agents may create additional subdirectories when necessary. Permanent application code, tests, and project documentation remain in their usual locations.

## Updating instructions

AgentsMD is designed to evolve with your projects.

You can add project-specific rules directly to the relevant instruction documents. Changes to the reusable templates in this repository can be distributed to future projects.

**The goal is simple: configure once, then let every AI agent follow the same development standards.**
